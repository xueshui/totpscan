# TOTP 认证器 隐私政策

**生效日期：2026-11-06**

本政策适用于浏览器扩展「TOTP 认证器」（Chrome / Microsoft Edge，Manifest V3）。它说明扩展会接触哪些数据、数据存放在哪里、以及在什么情况下会产生网络请求。

## 页面与语言版本

线上隐私政策是可直接托管的静态单文件页面：CSS 与脚本全部内联，不加载外部字体、脚本、图片或 CDN，也不引用扩展内其它文件；除下方 B 站空间链接外不含外部资源。五个 HTML 文件由同一套模板生成，正文与隐私承诺同源：

| 文件 | 初始语言 | 说明 |
| --- | --- | --- |
| `privacy.html` | 跟随浏览器 | 自动版，打开时按浏览器语言选择 |
| `privacy.zh-CN.html` | 简体中文 | 静态变体，锁定初始语言 |
| `privacy.zh-TW.html` | 繁體中文 | 静态变体，锁定初始语言 |
| `privacy.en.html` | English | 静态变体，锁定初始语言 |
| `privacy.ja.html` | 日本語 | 静态变体，锁定初始语言 |

自动判断规则：

- `zh-CN` / `zh-Hans` / `zh-SG`（以及其他非繁体中文）→ 简体中文；
- `zh-TW` / `zh-HK` / `zh-Hant` → 繁體中文；
- `ja*` → 日本語；
- `en*` → English；
- 其余语言（`ko`、`ar`、`ru` 等）→ 简体中文。

页面右上角提供「简体 / 繁體 / English / 日本語」手动切换与「跟随浏览器」入口；切换立即更新 `<html lang>`、标题与全部正文。手动选择写入 `localStorage`：自动版使用 `totpscan.privacy.lang`，四个静态变体分别使用 `totpscan.privacy.lang.zh_CN`、`.zh_TW`、`.en`、`.ja`，互不影响；刷新后仍然生效。「跟随浏览器」会清除当前页面对应的键，并按上述规则重新判断。未启用 JavaScript 时，页面显示简体中文正文。

## 1. 总则：不设服务器，不收集数据

- 本扩展**没有开发者服务器**，没有账号体系，不需要注册或登录。
- **不收集、不上传**任何个人数据到开发者或任何第三方。
- 不包含分析 SDK、广告 SDK、崩溃上报、遥测、A/B 实验或任何埋点。
- 不加载远程代码，所有脚本与样式均随扩展包分发。

开发者在任何情况下都无法查看用户的账户、密钥、验证码或使用记录。

## 2. 本地存储了哪些数据

以下数据仅保存在用户当前浏览器的扩展存储中（`chrome.storage.local` 与 IndexedDB），不会同步到云端：

| 数据 | 用途 | 说明 |
| --- | --- | --- |
| 账户显示名、签发方、账户标识、本地备注 | 在弹窗与设置页展示、排序、搜索 | 备注最长 64 个字符，仅本地可见 |
| TOTP 共享密钥 | 在本机计算动态码 | 以 AES-GCM 密文写入扩展存储；用于解密的 AES 密钥保存在 IndexedDB，创建时设置为不可导出（`extractable=false`） |
| 绑定的验证服务器地址 | 扫码登录时提交验证码 | 来自用户在绑定阶段扫描并确认的二维码 |
| 主题偏好 | 记住主题色与明暗模式 | 仅界面外观 |

上述数据不会离开本机，除非用户主动导出备份。用户可在设置页删除账户，或卸载扩展以清除本地数据。

## 3. 扫码登录时的网络请求

- 只有在用户主动发起扫码提交时，扩展才会把当前动态码 **POST 到用户在绑定阶段扫描并确认过的服务器地址**。
- 该地址由用户所在组织的服务端提供，**不经过开发者中转**，开发者不知道也无法访问该地址。
- 除向该地址提交验证码外，扩展**不发起任何外部网络请求**：没有统计上报、没有远程配置、没有字体或图片外链。
- 增强型（扫码）账户的动态码不在界面展示、不提供复制，只在提交时于本机内存中计算。

## 4. 读取网页内容的范围与目的

扩展不常驻任何网页，也没有声明全站内容脚本。只有在用户点击扩展图标或弹窗中的「扫码」按钮时，才会通过 `activeTab` + `chrome.scripting` 对**当前标签页临时注入**脚本，用于：

1. 读取当前页面中的图像、`canvas`、`svg` 或视频帧，识别其中的二维码；
2. 把动态码填入用户当前聚焦的输入框。

扩展**不采集、不记录、不外传**页面内容，不读取与上述目的无关的 DOM，也不会在用户未触发时注入或运行。

## 5. 剪贴板

- 仅在用户点击「复制」时写入动态码；
- 或当用户点击账户、但页面中没有可填写的输入框时，退化为静默复制动态码；
- 扩展**不读取剪贴板内容**，也不会把剪贴板内容发送到任何地方。

## 6. 备份、导入与导出

- 所有备份文件都在用户本机生成，导出内容直接交给浏览器下载，不经过网络。
- 可选的口令加密使用 PBKDF2-SHA256 派生密钥并以 AES-256-GCM 加密，口令不会被写入文件，也不保存在扩展中。
- 导入的文件只在本机解析；解析失败的行只在本地提示原因。
- 备份文件由用户自行保管。开发者无法访问、恢复或解密用户的备份文件。

## 7. 儿童隐私与政策变更

- 本扩展不面向儿童设计，也不收集任何用户数据，因此不存在收集儿童个人信息的情形。
- 政策发生变更时，会更新本页顶部的生效日期并在本页发布；涉及数据处理的重大变更，会同时在扩展更新说明中提示。
